# Orpheus

A landing page I built in August 2022 while I was learning HTML and CSS — just for fun.

It's a practice build of a dark, gold "Greek statue" portfolio template: a header that changes
as you scroll, a gallery of NFT cards, two feature panels with gradient borders and a contact
strip, responsive down to the phone.

**Live:** https://anumanuel.github.io/Orpheus/

## Built with

- HTML5 and CSS3 (custom properties, flexbox, gradients, `border-image`)
- A few lines of vanilla JavaScript for the scroll-aware header
- Google Fonts: Cinzel and Montserrat

No build step — open `index.html`, or serve the folder with any static server.
